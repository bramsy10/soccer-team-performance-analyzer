# Soccer Team Performance Analyzer

A small Python command line program that turns soccer match scores into a readable performance report.

## Features

- Records opponents and final scores
- Calculates wins, draws, losses, points, and goal difference
- Reports average goals, clean sheets, recent form, and the best result
- Validates all interactive input
- Saves the finished report as `soccer_report.txt`

## Run the program

Python 3.9 or newer is recommended. No external packages are required.

```bash
python3 soccer_analyzer.py
```

Follow the prompts to enter the team name and match results.

## Example

For results of 3–1, 1–1, and 0–2, the report gives one win, one draw, one loss, four points, a goal difference of zero, and form `W-D-L`.
